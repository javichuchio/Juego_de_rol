# React Native app

Proyecto creado en:
`mobile/react-native/JuegoDeRolMobile`

## Estructura base

- `src/screens`
- `src/services`
- `src/state`

## Ejecutar app Android

1. Levantar backend del proyecto principal en puerto 3001.
2. Ir a `mobile/react-native/JuegoDeRolMobile`.
3. Ejecutar `npx react-native run-android`.

Nota: `api.ts` usa `http://10.0.2.2:3001/api` (emulador Android).
